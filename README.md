# 🏥 MediScan AI - Intelligent Diagnostic Dashboard

MediScan is a Streamlit-based medical imaging application powered by Google Gemini 2.0 Flash. It provides real-time analysis of X-Rays and MRI scans, identifying organs, detecting anomalies, and generating professional clinical reports.

## ✨ Features
- **Multi-Modal Analysis:** Upload medical images for instant AI analysis.
- **Visual Annotation:** Bounding boxes drawn around detected anomalies.
- **Clinical Reports:** Generates downloadable, professional PDF reports.
- **AI Doctor Chat:** Context-aware chat assistant for follow-up questions.
- **Secure:** Uses environment variables for API security.
